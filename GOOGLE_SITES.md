# VYTAL AIR — Google Sites Integration

Google Sites does not import a complete custom HTML/CSS/JavaScript website as a native Google Sites theme.

## Recommended architecture

1. Publish the interactive VYTAL AIR site through GitHub Pages.
2. Open the VYTAL AIR Google Site.
3. Select **Insert → Embed → By URL**.
4. Paste the GitHub Pages address:

   `https://acoolnerd.github.io/VYTALAir/`

5. Set the embed to full width and increase the height so the page can be viewed comfortably.

## Recommended native Google Sites navigation

- Home
- Product System
- Physician Review
- Intellectual Property
- FDA Development
- Media Library
- Partner Inquiry

The GitHub Pages website should remain the interactive source. Google Sites can serve as the institutional wrapper, internal portal, or presentation entry point.

## Controlled communication

Keep all development-stage, physician-review, FDA, patent-status, and claims disclaimers in place until the relevant legal, regulatory, scientific, and clinical reviewers approve changes.
